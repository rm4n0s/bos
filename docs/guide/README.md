# User guide

Read in this order the first time; use it as a reference afterwards.

1. [How it fits together](concepts.md): the ideas and the words used everywhere.
2. [Install, configure, run](install.md)
3. [The catalogue](catalogue.md): servers, generators, fixers, groups, items and tags.
4. [The command language](commands.md): the one line that makes a batch.
5. [Running work](running.md): projects, commands, jobs, the REPL.
6. [Importing LoRAs from Civitai](civitai.md)
7. [The three ways in](interfaces.md): the web page, `bosctl`, the REST API and the event stream. An AI agent should read the [guide for agents](../agents.md).
8. [Configuration](configuration.md): every setting.

Short on time? Do the [tutorial](../tutorial.md) first, then come back here for what you need. When something goes wrong, [troubleshooting](../troubleshooting.md) lists every error by name.
